La creación del World Wide Web

Publicado el 25 de octubre de 2026

En marzo de 1989, el científico británico Tim Berners-Lee redactó una propuesta que pretendía mejorar la gestión y distribución de información en el CERN (Organización Europea para la Investigación Nuclear), utilizando el concepto de hipertexto.

Usando una computadora NeXTcube como el primer servidor web del mundo, Berners-Lee desarrolló las tres tecnologías esenciales que definieron la Web: el lenguaje HTML para estructurar contenido, el protocolo HTTP para la transferencia de datos y el sistema de direcciones URL.

La decisión del CERN de liberar el código de la World Wide Web al dominio público en 1993 permitió su expansión masiva y global sin restricciones de licencias.
